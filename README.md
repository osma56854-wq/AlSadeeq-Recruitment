# Al Sadeeq Al Araby – Overseas Recruitment

Official website for Al Sadeeq Al Araby Overseas Recruitment Company. A professional Arabic-first platform for job seekers to explore overseas employment services, submit applications, and connect with the recruitment team.

## Website
The static website is served from `index.html`.

## Deployment
Deploy this repository as a Static Site. Publish directory: `.` (repository root). No build command is required.

## Notes
Application submissions are stored in Supabase. Keep privileged Supabase keys out of client-side code.
